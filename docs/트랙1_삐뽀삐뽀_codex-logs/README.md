# 트랙1 삐뽀삐뽀 Codex 작업 로그

팀이 전달한 `트랙1_삐뽀삐뽀_codex-logs.zip`의 공개 제출용 사본입니다. GitHub 일반 파일 제한 때문에 48 MiB 이하의 6개 파일로 나눴습니다.

## 복원 방법

이 폴더의 모든 `*.partNNN`, `manifest.json`, `restore.py`를 같은 위치에 내려받은 뒤 실행합니다. 저장소를 clone했다면 이 폴더로 이동해 실행하세요.

```sh
python restore.py
```

Windows에서 `python` 명령이 없다면 `py restore.py`를 사용합니다. 같은 폴더에 `트랙1_삐뽀삐뽀_codex-logs.zip`이 만들어집니다. 스크립트는 각 조각과 전체 ZIP의 SHA-256을 확인하고 기존 파일을 덮어쓰지 않습니다. 각 조각을 따로 압축 해제하지 마세요.

## 공개본 처리 및 범위

- 원본 ZIP은 수정하지 않고 저장소 밖에 보존했습니다.
- 중첩 ZIP 안의 로그에 남은 AWS 서명 URL 8곳의 인증 쿼리를 `[REDACTED_SIGNED_QUERY]`로 치환했습니다. 공개본 SHA-256은 원본과 다릅니다.
- ZIP 8개, 일반 파일 33개의 CRC 및 정해진 자격 증명 패턴을 확인했습니다. 모든 개인정보나 모델 사용을 완전하게 감사했다는 뜻은 아닙니다.
- 팀이 전달한 중첩 ZIP 구조와 각자의 로그·AGENTS 파일을 유지했습니다. 팀 전체의 모든 AGENTS가 이 저장소의 프로젝트 규칙과 동일하다고 확인한 것은 아닙니다.
- 이 저장소의 실제 프로젝트 규칙은 [프로젝트 AGENTS.md](../../AGENTS.md)입니다. 개발 하네스는 OpenAI만 사용하도록 명시돼 있습니다.
- 외부 서버 증빙은 이 ZIP과 별도로 [server_logs/](../../server_logs/)의 5개 개별 파일로 제출합니다.

원본·공개본 및 분할 파일의 크기, SHA-256, 편집 범위는 `manifest.json`에 기록했습니다.
