## 로그 해석과 예외

과거 서버 인증 로그의 완전한 수집은 불가능했습니다. `03_remote_access.log`는 그 누락을 명시하고, 이번에 성공한 SSH 원격 조회 세션의 서버 제공 `SSH_CONNECTION` 값을 수집 시각과 함께 대체 스냅샷으로 기록합니다. `Accepted publickey` 같은 인증 원문을 만들어 넣지 않았습니다. `04_account_ip_list.csv`는 03의 현재 성공 세션에서 확인된 조합만 중복 제거한 것이며 과거 전체 접속 IP 목록이 아닙니다.

스냅샷에는 수집 목적의 신규 접속도 포함됩니다. 원본·가명본은 변조 불가능한 감사 기록이 아니며, 접속 성공만으로 작업 전체·참가자 신원·부정행위를 판정할 수 없습니다.
